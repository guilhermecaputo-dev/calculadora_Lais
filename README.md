# Calculadora de Aumento Percentual

Calculadora simples para comparar a quantidade de documentos entre dois meses.

## Fórmula

```text
(Mês atual - Mês passado) / Mês passado * 100
```

Exemplo:

```text
(106 - 49) / 49 * 100 = 116,33%
```

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Salve.
6. O GitHub irá gerar um endereço para acessar a calculadora.

Não é necessário servidor, banco de dados ou instalação.
